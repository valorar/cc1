1. Variables: nombres que guardan valores

Una variable asocia un nombre con un valor guardado en memoria. Se crea en el momento en que se le asigna algo, con el signo =:

ciudad = "Getafe"
temperatura = 18.5
alumnos = 27
hay_alerta = False

print(ciudad, temperatura, alumnos, hay_alerta)
Getafe 18.5 27 False
El = no significa «igual»En matemáticas, x = x + 1 es una ecuación sin solución. En programación es una instrucción perfectamente normal: calcula el valor de la derecha y guarda el resultado en el nombre de la izquierda. Se lee «x pasa a valer x más uno». Confundir la asignación con la igualdad matemática es uno de los tropiezos más comunes al empezar.
contador = 5
contador = contador + 1   # ahora vale 6
contador = contador * 2   # ahora vale 12
print(contador)
12

2. Los tipos de datos

Cada valor tiene un tipo, y el tipo determina qué operaciones tienen sentido con él. Los cuatro básicos:

TipoNombre en PythonQué representaEjemplos
EnterointNúmeros sin decimales, positivos o negativos.27, -4, 0
RealfloatNúmeros con decimales. El separador es el punto.18.5, -0.75
CadenastrTexto, siempre entre comillas."Getafe", "27"
BooleanoboolSolo dos valores: verdadero o falso.True, False

La función type() dice de qué tipo es un valor:

print(type(27))
print(type(18.5))
print(type("27"))
print(type(True))
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
Aquí está la respuesta a la pregunta guía"3" y 3 parecen lo mismo y no lo son: uno es texto y otro es un número. El operador + hace cosas distintas según el tipo: con números suma, con cadenas concatena. Por eso "3" + "4" vale "34" y 3 + 4 vale 7. Es la misma idea del Tema 4: los mismos bits significan cosas distintas según el código con que se interpreten.
print(3 + 4)        # 7    · suma de números
print("3" + "4")    # 34   · concatenación de texto
print("Hola " * 3)  # repite la cadena tres veces
7
34
Hola Hola Hola
Los decimales no son exactosPrueba print(0.1 + 0.2): Python responde 0.30000000000000004. No es un fallo de Python, sino una consecuencia de representar decimales en binario con un número finito de bits, como viste en el Tema 4. Práctica: nunca compares dos decimales con ==, y redondea al mostrar resultados.

3. Conversión de tipos

Para pasar de un tipo a otro se usan funciones con el nombre del tipo de destino:

print(int("42") + 1)      # texto a entero
print(float("3.5") * 2)   # texto a real
print(str(2026) + "-09")  # número a texto
print(int(9.87))          # trunca, no redondea
print(round(9.87))        # redondea de verdad
43
7.0
2026-09
9
10
💡 Ojo con int() sobre un decimal: trunca, es decir, se queda con la parte entera y descarta el resto. int(9.87) vale 9, no 10. Para redondear hay que usar round().

Si la conversión es imposible, el programa se detiene con un error:

numero = int("veinte")   # ValueError: invalid literal for int() with base 10: 'veinte'

Ese ValueError es un error de ejecución: el código es sintácticamente correcto, pero al ejecutarse se le pide algo imposible. Es una de las tres clases de error del Tema 9, y en el Tema 21 aprenderás a leer su mensaje completo.

Dos operadores que parecen menores y no lo sonLa división entera // y el módulo % resuelven media docena de problemas típicos. El módulo dice si un número es divisible entre otro —si n % 2 vale 0, n es par—, sirve para recorrer algo cíclicamente y para separar las cifras de un número. La división entera reparte en grupos completos.
minutos = 95

resto = minutos % 60
print(horas, "h", resto, "min")

print(10 % 2 == 0)   # ¿es par 10?
print(7 % 2 == 0)    # ¿es par 7?

💡 En Python 3, / siempre devuelve un decimal, aunque la división sea exacta: 6 / 3 vale 2.0, no 2. Si necesitas un entero, usa //.

5. Operadores relacionales y lógicos

5.1. Relacionales

Comparan dos valores y devuelven siempre un booleano:

OperadorSignificaEjemploResultado
==Igual a5 == 5True
!=Distinto de5 != 3True
< >Menor / mayor que3 < 5True
<= >=Menor o igual / mayor o igual5 >= 5True
Un = asigna; dos == comparanEs el error tipográfico más frecuente de todo el curso. nota = 5 guarda un 5 en la variable; nota == 5 pregunta si vale 5. Si los confundes dentro de una condición, Python te avisará con un error de sintaxis, pero conviene tenerlo claro desde el principio.

5.2. Lógicos

Son las operaciones del álgebra de Boole del Tema 1, ahora ejecutables:

nota = 7
asistencia = 90

print(nota >= 5 and asistencia >= 80)   # ambas condiciones
print(nota >= 9 or asistencia >= 80)    # al menos una
print(not (nota >= 5))                  # niega la condición
True
True
False
💡 Python permite encadenar comparaciones igual que en matemáticas: 0 <= nota <= 10 equivale a nota >= 0 and nota <= 10, y se lee mucho mejor. Es una de las razones por las que su código resulta tan legible.

6. Expresiones y precedencia

Una expresión combina valores, variables y operadores para producir un resultado. Python la evalúa siguiendo un orden de precedencia:

PrioridadOperadores
1.ª (mayor)Paréntesis ( )
2.ªPotencia **
3.ª*, /, //, %
4.ª+, -
5.ªComparaciones ==, !=, <, >, <=, >=
6.ªnot, después and, después or
print(2 + 3 * 4)      # 14, no 20: la multiplicación va antes
print((2 + 3) * 4)    # 20: los paréntesis mandan
print(10 - 2 - 3)     # 5: se evalúa de izquierda a derecha
14
20
5
Criterio prácticoNo hace falta memorizar la tabla entera: usa paréntesis siempre que la expresión no sea evidente de un vistazo. Un paréntesis de más no cuesta nada y hace explícita tu intención; una precedencia mal recordada produce un error de lógica que nadie detecta.

7. Entrada de datos con input()

La función input() detiene el programa, muestra un mensaje y espera a que el usuario escriba algo y pulse Intro:

nombre = input("¿Cómo te llamas? ")
print("Hola,", nombre)
La regla que hay que grabar a fuegoinput() devuelve siempre una cadena de texto, aunque el usuario escriba un número. Si vas a operar con ese dato, tienes que convertirlo antes. Es la causa número uno de errores en los primeros programas.
# Mal: concatena texto en lugar de sumar
edad = input("Tu edad: ")
print(edad + 1)          # TypeError: can only concatenate str (not "int") to str

# Bien: convierte antes de operar
edad = int(input("Tu edad: "))
print("El año que viene tendrás", edad + 1)
Tu edad: 16
El año que viene tendrás 17
💡 Si el usuario escribe algo que no es un número, int() lanzará un ValueError y el programa se detendrá. Comprobar la entrada antes de convertirla es parte del Tema 21; de momento, basta con que sepas que ese riesgo existe y con que lo tengas en cuenta al probar tus programas.

8. Salida con print() y cadenas f

print() admite varios valores separados por comas, y los muestra separados por un espacio:

producto = "Cuaderno"
precio = 3.5
unidades = 4
print("Producto:", producto, "| Unidades:", unidades)
Producto: Cuaderno | Unidades: 4

8.1. Cadenas f

La forma cómoda de construir texto con valores dentro es una cadena f: se antepone f a las comillas y se escriben las expresiones entre llaves.

producto = "Cuaderno"
precio = 3.5
unidades = 4
total = precio * unidades

print(f"{unidades} x {producto}: {total} €")
print(f"{unidades} x {producto}: {total:.2f} €")
print(f"El doble sería {total * 2:.2f} €")
4 x Cuaderno: 14.0 €
4 x Cuaderno: 14.00 €
El doble sería 28.00 €
FormatoQué haceEjemplo con total = 14.0
{total}Muestra el valor tal cual.14.0
{total:.2f}Dos decimales.14.00
{total:.0f}Sin decimales, redondeando.14
{total:8.2f}Dos decimales, alineado en 8 caracteres.   14.00
💡 Recuerda la distinción del Tema 12 entre valor y formato: {total:.2f} cambia cómo se muestra el número, no su valor. El cálculo siguiente seguirá usando todos los decimales. Si quieres cambiar el valor, usa round().

9. Constantes, nombres y legibilidad

9.1. Constantes

Un valor fijo que aparece en varios sitios debe estar en una variable con nombre, no repetido dentro de las fórmulas. Por convención se escriben en mayúsculas para indicar que no deben cambiar durante la ejecución:

# Mal: ¿qué es 0.21? ¿Y si mañana cambia?
total = base * 1.21

# Bien: el nombre lo explica y se cambia en un solo sitio
IVA = 0.21
total = base * (1 + IVA)
Números mágicosSe llama número mágico a una cifra suelta en medio del código sin explicación. Es un problema doble: nadie sabe qué significa, y si aparece en cinco sitios hay que acordarse de cambiarla en los cinco. Es exactamente el mismo criterio que en el Tema 12: el IVA va en una celda, no dentro de cada fórmula.

9.2. Nombres que explican

En vez de…Escribe…Por qué
x, a, dato2temperatura, nota_mediaEl nombre dice qué guarda, sin tener que buscarlo.
listanotas, alumnosDescribe el contenido, no el tipo.
flaghay_alerta, es_validoLos booleanos se leen mejor como una afirmación.
💡 Se dice que el código se escribe una vez y se lee muchas: por otras personas, y por ti mismo dentro de dos semanas, cuando ya no recuerdes nada. Un buen nombre es la documentación más barata que existe, porque no hay que mantenerla aparte.

9.3. Un programa completo

Reuniendo todo lo del tema:

# Calcula el importe de una compra con IVA y descuento.
IVA = 0.21
DESCUENTO_MINIMO = 50      # € a partir de los cuales se aplica descuento
PORCENTAJE_DESCUENTO = 0.10

producto = input("Producto: ")
unidades = int(input("Unidades: "))
precio = float(input("Precio unitario en €: "))

subtotal = precio * unidades
tiene_descuento = subtotal >= DESCUENTO_MINIMO
descuento = subtotal * PORCENTAJE_DESCUENTO if tiene_descuento else 0
total = (subtotal - descuento) * (1 + IVA)

print(f"{unidades} x {producto}")
print(f"Subtotal:   {subtotal:8.2f} €")
print(f"Descuento:  {descuento:8.2f} €")
print(f"Total:      {total:8.2f} €")
Producto: Cuaderno
Unidades: 20
Precio unitario en €: 3.5
20 x Cuaderno
Subtotal:      70.00 €
Descuento:      7.00 €
Total:         76.23 €
🤔 Para pensar: en ese programa hay una línea con una construcción que aún no hemos explicado, la que decide el descuento según una condición. En el Tema 18 la escribirás de forma mucho más clara con if. Mientras tanto, comprueba los ejemplos: ¿qué pasa si compras 10 unidades en lugar de 20? ¿Y si escribes 3,5 con coma en vez de con punto?

Resumen esencial

  1. La asignación no es una igualdad: calcula la derecha y guarda el resultado en la izquierda.
  2. Cada valor tiene un tipo, y el tipo decide qué hace cada operador: + suma números y concatena cadenas.
  3. int() trunca y round() redondea; los decimales binarios no son exactos, así que no se comparan con ==.
  4. // y % resuelven muchos problemas típicos, empezando por saber si un número es par.
  5. Los operadores lógicos son el álgebra de Boole del Tema 1, ya ejecutable.
  6. Ante la duda con la precedencia, pon paréntesis: hacen explícita tu intención.
  7. input() devuelve siempre texto: hay que convertirlo antes de operar.
  8. Las cadenas f construyen la salida con formato, y el formato no cambia el valor.
  9. Un valor fijo va en una constante con nombre, nunca suelto dentro de una fórmula.
