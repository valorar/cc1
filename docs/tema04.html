1. Qué es un sistema informático

Un montón de piezas sobre una mesa no es un ordenador. Un ordenador sin programas tampoco sirve de nada. Y un equipo perfectamente instalado que nadie sabe usar no resuelve ningún problema. Por eso, en informática no se habla de «máquina» sino de sistema informático: un conjunto de elementos que solo funcionan juntos.

DefiniciónUn sistema informático es el conjunto formado por el subsistema físico (hardware), el subsistema lógico (software) y las personas que lo utilizan y lo mantienen, organizados para tratar información de forma automática y cumplir una finalidad.

Fíjate en que la definición incluye dos cosas que suelen olvidarse: las personas y la finalidad. El aula de informática del instituto y el sistema informático de un hospital pueden tener hardware parecido; son sistemas distintos porque persiguen fines distintos, los usan personas con perfiles distintos y ejecutan software distinto.

Hardware

Todo lo que se puede tocar: procesador, memoria, almacenamiento, periféricos, cables. Es la parte que ejecuta.

Software

Los programas y los datos. No tiene existencia física: es información que dirige al hardware.

Personas

Quienes diseñan, programan, administran y usan el sistema. Sin ellas, el sistema no tiene propósito.

💡 Algunos autores añaden dos elementos más: los datos —que a veces se cuentan dentro del software— y los procedimientos, es decir, las normas escritas sobre cómo se usa el sistema. La clasificación oficial de esta asignatura usa tres subsistemas, pero conviene saber que la frontera entre ellos es una convención útil, no una ley natural.

2. Subsistema físico y subsistema lógico

La distinción entre hardware y software parece obvia, pero tiene matices que conviene fijar desde ahora.

Subsistema físico (hardware)Subsistema lógico (software)
NaturalezaMaterial: circuitos, metales, plásticos.Inmaterial: información codificada.
Se estropea…Por desgaste, golpes, calor o electricidad.No se desgasta: falla por errores de diseño o por corrupción de los datos.
Copiar cuesta…Fabricar otra unidad completa.Prácticamente nada.
Se repara…Sustituyendo o arreglando la pieza.Corrigiendo el código y publicando una nueva versión.
EjemplosProcesador, memoria RAM, teclado, impresora.Sistema operativo, navegador, un archivo de texto.

2.1. El caso raro: el firmware

Entre ambos hay una zona intermedia. El firmware es software, porque es un programa, pero está grabado en un chip de la propia placa y es imprescindible para que el hardware arranque siquiera. La UEFI de tu ordenador, el programa interno de una impresora o el de un router son firmware. Se puede actualizar, pero no se instala ni se desinstala como una aplicación normal. Lo estudiarás en el Tema 6.

3. Las personas: perfiles del sistema

El currículo de esta asignatura menciona expresamente a las personas como tercer subsistema, y lo hace enumerando perfiles profesionales. Estos son los principales, aunque en organizaciones pequeñas una misma persona asuma varios:

PerfilDe qué se ocupaPregunta que responde
AnalistaEstudia el problema, habla con quien lo tiene y define qué debe hacer el sistema y cómo se organizará.¿Qué hay que construir y por qué?
ProgramadorEscribe, prueba y corrige el código que implementa esa solución.¿Cómo se construye?
Administrador de sistemasInstala, configura, actualiza y vigila los equipos, las redes y las copias de seguridad.¿Cómo se mantiene funcionando?
OperarioEjecuta las tareas rutinarias de explotación del sistema según procedimientos establecidos.¿Cómo se opera cada día?
Usuario finalUtiliza el sistema para su trabajo, sin necesidad de conocer cómo está construido.¿Para qué sirve?
🤔 Para pensar: muchos fallos graves de sistemas informáticos reales no se deben a un error del hardware ni a un fallo del código, sino a que el analista entendió mal el problema o a que el procedimiento de uso era confuso. Si las personas forman parte del sistema, ¿tiene sentido llamar «error humano» a un fallo y dar el asunto por cerrado?

4. La información en binario: bit y byte

Antes de estudiar cómo funciona la máquina hay que entender en qué formato guarda lo que maneja. Un circuito digital distingue con fiabilidad dos estados eléctricos estables: hay tensión o no la hay. Representamos esos dos estados como 0 y 1, y a cada uno lo llamamos bit (binary digit).

Concepto claveUn bit no significa nada por sí solo. El significado depende del código acordado. La secuencia 01000001 vale 65 si la interpretamos como un número, la letra A si la interpretamos con el código ASCII, y un tono de gris muy oscuro si la interpretamos como el brillo de un píxel.

4.1. Cuántas cosas se pueden representar

Con n bits se pueden distinguir 2n combinaciones distintas. La progresión crece muy deprisa:

BitsCombinacionesEjemplo de uso
12Sí / no, encendido / apagado
416Un dígito hexadecimal
8 (un byte)256Un carácter ASCII, o la intensidad de un color
1665.536Una muestra de sonido de calidad CD
2416.777.216Un color RGB completo
324.294.967.296Una dirección IPv4

Ocho bits forman un byte, que es la unidad práctica con la que se mide casi todo. Es la cantidad de información que históricamente bastaba para almacenar un carácter de texto.

4.2. Leer un número binario

El sistema binario funciona igual que el decimal, pero con potencias de 2 en lugar de potencias de 10. Cada posición vale el doble que la anterior, empezando por la derecha:

Posición1286432168421
Bits01000001

Para saber cuánto vale, se suman los valores de las posiciones que tienen un 1: 64 + 1 = 65. Para el camino inverso, se va restando la mayor potencia de 2 que quepa: 200 − 128 = 72; 72 − 64 = 8; 8 − 8 = 0, así que 200 se escribe 11001000.

💡 Con 8 bits se representan los números del 0 al 255, que son 256 valores. Por eso los componentes de un color RGB van de 0 a 255, y por eso cada número de una dirección IPv4 también. No es una casualidad ni una convención estética: es el rango exacto de un byte.
Los códigos de caracteres van en su temaCómo se decide que 01000001 represente la letra A —los códigos ASCII y Unicode— lo estudiarás en el Tema 19, cuando trabajes con cadenas de texto en Python y necesites usarlo. Aquí basta con retener que hace falta un código y que sin él los bits no significan nada.

5. Los múltiplos y el kilo que no vale mil

Como los bytes se cuentan por miles de millones, se usan múltiplos. Y aquí aparece una de las confusiones más extendidas de toda la informática.

El Sistema Internacional define los prefijos en potencias de 10: un kilo son mil. Pero los ordenadores trabajan en potencias de 2, y 210 = 1.024 se parece bastante a mil, así que durante décadas se llamó «kilobyte» a 1.024 bytes. La ambigüedad se arrastra hasta hoy.

Prefijo decimal (SI)ValorPrefijo binario (IEC)ValorDiferencia
kilobyte (kB)103 = 1.000kibibyte (KiB)210 = 1.0242,4 %
megabyte (MB)106mebibyte (MiB)2204,9 %
gigabyte (GB)109gibibyte (GiB)2307,4 %
terabyte (TB)1012tebibyte (TiB)24010,0 %
Por qué tu disco de 1 TB tiene 931 GBEl fabricante vende 1 TB en unidades decimales: 1.000.000.000.000 bytes exactos. Windows divide esa cifra entre 1.024 tres veces y muestra 931… pero lo etiqueta como «GB» en lugar de «GiB». Nadie miente: son la misma cantidad de bytes expresada en dos escalas distintas con la misma etiqueta. La diferencia crece con el tamaño: en un disco de 4 TB son casi 400 GB de «desajuste» aparente.

5.1. Bits y bytes: la otra confusión

Hay una segunda trampa, y esta sí cuesta dinero. Por convención:

  • el almacenamiento se mide en bytes, con B mayúscula: MB, GB, TB;
  • la velocidad de transmisión se mide en bits por segundo, con b minúscula: Mb/s, Gb/s.

Como un byte son ocho bits, una conexión de 600 Mb/s descarga como máximo 75 MB/s: hay que dividir entre 8. Un archivo de 1,5 GB tardará unos veinte segundos, no dos y medio.

📶 ¿Sabías que…? Las operadoras anuncian siempre la velocidad en megabits por segundo, porque el número resulta ocho veces mayor y suena mucho mejor. Es perfectamente legal y perfectamente correcto: solo hay que saber leerlo. Mira la letra: Mb no es MB.

6. Capacidad, velocidad, latencia y frecuencia

Cuatro magnitudes distintas que se confunden constantemente. Cada una responde a una pregunta diferente y ninguna sustituye a las demás.

MagnitudPregunta que respondeUnidad habitualEjemplo
Capacidad¿Cuántos datos caben?GB, TBUn SSD de 1 TB
Ancho de banda¿Cuántos datos pasan por segundo?MB/s, Gb/sUna conexión de 1 Gb/s
Latencia¿Cuánto se tarda en empezar a responder?ms, µs, nsUn disco duro tarda unos 8 ms en posicionarse
Frecuencia¿Cuántos ciclos ocurren por segundo?MHz, GHzUn procesador a 4 GHz

Un dispositivo puede tener mucha capacidad y ser lento, o mucho ancho de banda y una latencia molesta. La comparación clásica: un camión cargado de discos duros que cruza España tiene un ancho de banda enorme —mueve petabytes— y una latencia pésima: ocho horas hasta el primer byte.

Más gigahercios no es más rápidoLa frecuencia solo dice cuántos ciclos por segundo ejecuta el reloj, no cuánto trabajo se hace en cada ciclo. Un procesador moderno a 3 GHz rinde muchísimo más que uno de hace quince años a 3 GHz, porque hace más operaciones por ciclo y tiene más núcleos. Comparar frecuencias entre procesadores de familias distintas no sirve para nada. Lo verás en detalle en el Tema 5.

7. Personales, departamentales y grandes ordenadores

La clasificación clásica ordena los equipos por potencia, número de usuarios simultáneos y ámbito de uso.

7.1. Ordenadores personales

Pensados para un usuario cada vez. Sobremesa, portátiles, todo-en-uno y estaciones de trabajo. Es el segmento con diferencia más numeroso y el que tienes delante en el aula. Una estación de trabajo es un ordenador personal de gama alta destinado a tareas exigentes —diseño 3D, edición de vídeo, cálculo científico—, con más memoria, almacenamiento rápido y una tarjeta gráfica potente.

7.2. Sistemas departamentales

Equipos intermedios que dan servicio simultáneo a un grupo de usuarios: el servidor de archivos de un instituto, el que gestiona las cuentas y las impresoras, el que aloja la aplicación de una empresa mediana. Suelen llamarse servidores y estar diseñados para funcionar sin interrupción: componentes redundantes, discos que se cambian en caliente y fuentes de alimentación duplicadas.

7.3. Grandes ordenadores

Dentro de esta categoría conviene distinguir dos cosas que se confunden a menudo porque las dos son «enormes»:

Mainframe

Optimizado para procesar muchísimas transacciones a la vez con una fiabilidad extrema. Bancos, aerolíneas y administraciones los siguen usando: cada vez que sacas dinero de un cajero, probablemente hay uno detrás.

Supercomputador

Optimizado para cálculo masivo: predicción del clima, simulación de moléculas, entrenamiento de modelos de IA. Es un conjunto de miles de nodos trabajando en paralelo sobre un mismo problema.

🇪🇸 ¿Sabías que…? El supercomputador más potente de España es el MareNostrum 5, del Barcelona Supercomputing Center, y está instalado en la capilla desacralizada de Torre Girona: una nave de cristal dentro de una iglesia del siglo XIX. Se usa para investigación en clima, biomedicina, materiales e inteligencia artificial, y cualquier grupo de investigación europeo puede solicitar tiempo de cálculo en él.

8. Otros formatos actuales

La clasificación anterior es la del currículo y sigue siendo útil, pero se quedó fijada cuando un ordenador era una caja sobre una mesa. Hoy hay que añadir al menos cuatro categorías más:

FormatoQué lo caracterizaCompromiso que asume
PortátilesOrdenador personal completo con batería y pantalla integradas.Menos rendimiento sostenido y menos ampliable a cambio de movilidad.
Dispositivos móvilesMóviles y tabletas: procesador de bajo consumo, sensores integrados, conectividad permanente.Autonomía y tamaño por encima de la potencia bruta; poca o ninguna capacidad de ampliación.
Sistemas embebidosOrdenador dedicado a una única función dentro de otro aparato: lavadora, coche, marcapasos, semáforo.Recursos mínimos y coste bajísimo a cambio de no ser de propósito general.
Servidores en la nubeCapacidad de cálculo alquilada en centros de datos remotos, ampliable bajo demanda.Se paga por uso y se evita comprar equipos, pero se depende de la red y de un proveedor.
💡 Un coche actual puede llevar más de cien pequeños ordenadores empotrados coordinando frenos, motor, climatización y asistentes de conducción. Numéricamente, la inmensa mayoría de los procesadores que se fabrican en el mundo no van a ordenadores personales: van a sistemas embebidos.

9. Criterios de clasificación

Ninguna clasificación es la «verdadera». Cada una responde a un criterio, y lo útil es saber cuál se está aplicando:

CriterioPreguntaCategorías que produce
Prestaciones¿Cuánta capacidad de cálculo tiene?Desde el microcontrolador hasta el supercomputador.
Usuarios simultáneos¿A cuántas personas atiende a la vez?Monousuario, departamental, corporativo.
Uso previsto¿Para qué se ha diseñado?Propósito general o dedicado a una única función.
Movilidad¿Está fijo o se transporta?Sobremesa, portátil, dispositivo móvil, wearable.
Coste y ciclo de vida¿Cuánto cuesta comprarlo y mantenerlo?Doméstico, profesional, industrial.
Criterio claveLa pregunta útil no es «¿qué tipo de ordenador es este?», sino «¿para qué problema se diseñó y qué sacrificó a cambio?». Todo equipo es un compromiso entre potencia, consumo, tamaño, fiabilidad y precio; entender qué se sacrificó explica casi todas sus características.

Glosario del tema

Sistema informático
Conjunto de hardware, software y personas organizado para tratar información con una finalidad.
Hardware
Subsistema físico: todos los componentes materiales del sistema.
Software
Subsistema lógico: los programas y los datos que dirigen al hardware.
Firmware
Programa grabado en un chip del propio equipo, imprescindible para que el hardware funcione.
Bit
Unidad mínima de información; distingue entre dos estados, 0 y 1.
Byte
Agrupación de ocho bits; permite 256 combinaciones distintas.
Kibibyte (KiB)
1.024 bytes; prefijo binario, frente al kilobyte decimal de 1.000 bytes.
Ancho de banda
Cantidad de datos transferidos por unidad de tiempo.
Latencia
Tiempo que transcurre hasta que comienza o se completa una respuesta.
Frecuencia
Número de ciclos por segundo; se mide en hercios y sus múltiplos.
Estación de trabajo
Ordenador personal de altas prestaciones destinado a tareas técnicas exigentes.
Mainframe
Gran ordenador optimizado para procesar enormes volúmenes de transacciones con máxima fiabilidad.
Supercomputador
Conjunto de miles de nodos que trabajan en paralelo sobre problemas de cálculo masivo.
Sistema embebido
Ordenador dedicado a una función concreta dentro de otro aparato.

Resumen esencial

  1. Un sistema informático son tres subsistemas —hardware, software y personas— trabajando con una finalidad; ninguno funciona solo.
  2. El firmware ocupa la frontera: es software, pero vive grabado en el hardware.
  3. Un bit no significa nada sin un código: la misma secuencia puede ser un número, una letra o un color.
  4. Con n bits hay 2ⁿ combinaciones; un byte son 8 bits y 256 valores posibles, de 0 a 255.
  5. Los prefijos decimales (kB, MB, GB) y los binarios (KiB, MiB, GiB) no valen lo mismo, y esa es la razón de que un disco de 1 TB muestre 931 GB.
  6. El almacenamiento se mide en bytes y la transmisión en bits: hay que dividir entre 8.
  7. Capacidad, ancho de banda, latencia y frecuencia responden a preguntas distintas y más gigahercios no significa más velocidad.
  8. Todo equipo, del microcontrolador al supercomputador, es un compromiso entre potencia, consumo, tamaño, fiabilidad y precio.
