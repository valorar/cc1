1. Por qué hacen falta las colecciones

Con lo que sabes hasta ahora, guardar las notas de un grupo exigiría escribir nota1, nota2, nota3… hasta treinta. Y después habría que sumarlas una a una. Con cuarenta alumnos, habría que reescribir el programa.

Aquí está la respuesta a la pregunta guíaUna lista guarda muchos valores bajo un único nombre. Combinada con el bucle for del Tema 18, permite escribir un programa que funciona igual con tres notas que con tres mil, sin cambiar una línea. El texto oficial del currículo habla de «vectores»; en Python su realización natural son las listas.

3. Añadir, modificar y eliminar

A diferencia de las cadenas, las listas se pueden modificar después de creadas:

notas = [7, 4, 9]

notas[1] = 6            # modificar por índice
notas.append(8)         # añadir al final
notas.insert(0, 10)     # insertar en una posición
print(notas)

notas.remove(6)         # eliminar la primera aparición de un valor
ultima = notas.pop()    # sacar el último y quedárselo
print(notas, "| retirada:", ultima)
[10, 7, 6, 9, 8]
[10, 7, 9] | retirada: 8
OperaciónQué hace
lista.append(x)Añade x al final.
lista.insert(i, x)Inserta x en la posición i.
lista.remove(x)Elimina la primera aparición del valor x.
lista.pop()Saca y devuelve el último elemento.
lista.pop(i)Saca y devuelve el elemento de la posición i.
lista.clear()Vacía la lista.
No modifiques una lista mientras la recorresSi eliminas elementos dentro de un for que está recorriendo esa misma lista, las posiciones se desplazan y el bucle se saltará elementos sin avisar. La solución habitual es construir una lista nueva con lo que quieres conservar, como verás en el apartado 5.

4.1. Ordenar

notas = [7, 4, 9, 5]

ordenadas = sorted(notas)          # devuelve una lista nueva
print(ordenadas)
print(notas)                       # la original no cambia

print(sorted(notas, reverse=True)) # de mayor a menor

notas.sort()                       # ordena la propia lista
print(notas)
[4, 5, 7, 9]
[7, 4, 9, 5]
[9, 7, 5, 4]
[4, 5, 7, 9]
Dos familias de operacionesFíjate en la diferencia, porque se repite por toda la biblioteca de Python: sorted(lista) devuelve una lista nueva y deja intacta la original; lista.sort() modifica la lista y no devuelve nada. Escribir notas = notas.sort() es un error clásico: deja notas valiendo None.

5. Listas y bucles: construir resultados

El patrón más útil de todo el tema: empezar con una lista vacía e ir añadiendo lo que interesa.

notas = [7, 4, 9, 5, 8, 3]

# Filtrar: quedarse con los que cumplen una condición
aprobadas = []
for nota in notas:
    if nota >= 5:
        aprobadas.append(nota)

# Transformar: aplicar un cálculo a cada elemento
sobre_100 = []
for nota in notas:
    sobre_100.append(nota * 10)

print("Aprobadas:", aprobadas)
print("Sobre 100:", sobre_100)
Aprobadas: [7, 9, 5, 8]
Sobre 100: [70, 40, 90, 50, 80, 30]
Tres operaciones que lo resuelven casi todoFiltrar (quedarse con algunos), transformar (aplicar un cálculo a cada uno) y resumir (reducir todos a un valor). Casi cualquier tratamiento de datos es una combinación de estas tres, y las tres se escriben con el mismo esqueleto: lista vacía, bucle, condición o cálculo, append.

6. Las cadenas también son secuencias

Una cadena de texto es una secuencia de caracteres, así que casi todo lo de las listas vale para ella:

palabra = "Computación"

print(len(palabra))
print(palabra[0])
print(palabra[-1])
print(palabra[0:5])     # troceado
print(palabra[::-1])    # al revés
print("uta" in palabra)

Las cadenas no se pueden modificarIntentar palabra[0] = "c" produce un TypeError. Se dice que las cadenas son inmutables: no se cambian, se crean nuevas. Por eso todos los métodos del apartado siguiente devuelven una cadena nueva en lugar de alterar la original. Es la diferencia principal entre una lista y una cadena.

8. Codificación de caracteres: ASCII y Unicode

En el Tema 4 quedó pendiente una pregunta: si un ordenador solo guarda números, ¿cómo guarda una letra? La respuesta es un código que asigna un número a cada carácter.

8.1. ASCII

ASCII, de 1963, asigna un número del 0 al 127 a las letras inglesas, los dígitos, los signos de puntuación y algunos caracteres de control. Cabe en 7 bits.

print(ord("A"), ord("a"), ord("0"))
print(chr(65), chr(97), chr(233))
65 97 48
A a é
🔤 ¿Sabías que…? Los códigos no son arbitrarios. La A es 65 y la a es 97: exactamente 32 de diferencia, que es 25. Cambiar entre mayúscula y minúscula consistía en encender o apagar un solo bit. Y los dígitos empiezan en el 48, de modo que restando 48 al código se obtiene el valor numérico. Fueron decisiones de ingeniería tomadas cuando cada operación contaba.

8.2. Unicode

127 caracteres no dan ni para el español. Durante años cada país usó su propia extensión, y de ahí venían los textos llenos de símbolos raros al abrirlos en otro equipo. Unicode resolvió el problema asignando un número único a todos los caracteres de todas las escrituras: latino, griego, cirílico, árabe, chino, emoji.

La forma habitual de almacenarlo es UTF-8, que usa un byte para los caracteres ASCII y hasta cuatro para el resto. Python 3 trabaja en Unicode de forma nativa:

texto = "Año ñ é 中 🙂"
print(len(texto))
print(ord("ñ"), ord("中"))
11
241 20013
💡 Esto explica del todo la tercera trampa del CSV que viste en el Tema 12: si un archivo se guarda con una codificación y se abre con otra, las tildes y las eñes se convierten en símbolos ilegibles. La solución es siempre la misma: UTF-8 en todas partes.

9. Listas de listas: tablas sencillas

Una lista puede contener otras listas, y eso permite representar una tabla: cada lista interior es una fila.

# Cada fila: nombre, nota de teoría, nota de práctica
alumnado = [
    ["Ana", 7, 8],
    ["Luis", 4, 6],
    ["Marta", 9, 9],
]

print(alumnado[0])       # una fila completa
print(alumnado[0][0])    # fila 0, columna 0
print(alumnado[1][2])    # fila 1, columna 2

for fila in alumnado:
    nombre = fila[0]
    media = (fila[1] + fila[2]) / 2
    estado = "apto" if media >= 5 else "no apto"
    print(f"{nombre:8s} media {media:.1f}  {estado}")
['Ana', 7, 8]

El límite de esta representaciónfila[1] no dice nada sobre qué contiene: hay que recordar que la columna 1 es la nota de teoría. Con tres columnas se lleva bien; con quince, es una fuente segura de errores. En Ciencias de la Computación II usarás diccionarios, donde cada dato se identifica por un nombre —fila["teoria"]— en lugar de por su posición.

El criterio de fondoElegir bien la estructura de datos simplifica el algoritmo antes de escribirlo. Muchos programas complicados lo son porque los datos están guardados de una forma que no encaja con lo que hay que hacer con ellos. Glosario del tema

Lista
Colección ordenada y modificable de valores, escrita entre corchetes.
Índice
Posición de un elemento dentro de una secuencia; empieza en cero.
Índice negativo
Posición contada desde el final; -1 es el último elemento.
Troceado
Extracción de una porción de una secuencia mediante [inicio:fin].
append()
Método que añade un elemento al final de una lista.
Filtrar
Construir una colección nueva con los elementos que cumplen una condición.
Transformar
Construir una colección nueva aplicando un cálculo a cada elemento.
Inmutable
Dicho de un valor que no puede modificarse; los métodos devuelven uno nuevo.
split()
Método que parte una cadena y devuelve una lista.
join()
Método que une los elementos de una lista en una cadena.
ASCII
Código de 1963 que asigna un número del 0 al 127 a los caracteres básicos.
Unicode
Norma que asigna un número único a los caracteres de todas las escrituras.
UTF-8
Forma habitual de almacenar Unicode, con longitud variable de uno a cuatro bytes.
Lista anidada
Lista cuyos elementos son a su vez listas; permite representar tablas.

Resumen esencial

  1. Una lista guarda muchos valores bajo un nombre y, con un bucle, hace que el programa funcione con cualquier cantidad de datos.
  2. Los índices empiezan en cero, el último es len - 1 y -1 es un atajo para el último.
  3. Las listas se modifican; conviene no hacerlo mientras se recorren.
  4. sorted() devuelve una lista nueva y .sort() modifica la existente sin devolver nada.
  5. Filtrar, transformar y resumir resuelven casi cualquier tratamiento de datos, con el mismo esqueleto de bucle.
  6. Las cadenas son secuencias, pero inmutables: sus métodos devuelven una cadena nueva.
  7. split() y join() conectan el mundo del texto con el de las listas.
  8. ASCII cubre 128 caracteres; Unicode los cubre todos, y UTF-8 es la forma habitual de guardarlo.
  9. Una lista de listas representa una tabla, pero acceder por posición se vuelve inmanejable al crecer.
